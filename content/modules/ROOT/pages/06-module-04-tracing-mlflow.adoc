== MLflow 跟踪简介

MLflow 跟踪是一个与 OpenTelemetry 兼容的 LLM 可观测性解决方案，它捕获请求每个步骤的输入、输出和元数据。对于 Fed Aura Capital，这意味着对跨代理的贷款申请完整路径的可见性，每个带有其 prompt 和响应的 LLM 调用，所有工具调用和代理决策点。每个请求创建一个**跟踪**（完整的请求流程），由**跨度**（LLM 调用或工具调用等单个操作）组成，组织成显示什么调用什么的父子树。

== 跟踪如何工作？

当你部署 mortgage-ai 应用程序时，跟踪已启用。你从未需要手动配置它。每个 LLM 调用、工具调用和代理决策都自动记录。这是如何实现的。

=== MLflow 自动日志记录：一行跟踪

MLflow 跟踪与 https://mlflow.org/docs/latest/genai/tracing/integrations/#agent-frameworks-python[40+ 流行的 LLM 和 AI 代理框架^] 集成，提供**一行自动跟踪**体验。在应用程序启动时调用 `autolog()` 一次，所有 LangChain 操作（LLM 调用、工具调用、代理决策）都会自动捕获——无需更改代理逻辑。

mortgage-ai 应用程序使用 https://mlflow.org/docs/latest/genai/tracing/integrations/listing/langchain/[LangChain 自动日志记录^]。在 https://github.com/rh-ai-quickstart/multi-agent-loan-origination/blob/main/packages/api/src/observability.py#L105[observability.py^] 中，整个跟踪设置是：

[source,python]
----
import mlflow
import mlflow.langchain

mlflow.set_tracking_uri(settings.MLFLOW_TRACKING_URI)
mlflow.set_experiment(settings.MLFLOW_EXPERIMENT_NAME)
mlflow.langchain.autolog()  # <1>
----
<1> 这一行启用所有 LangChain 和 LangGraph 操作的自动跟踪：每个 LLM 调用、工具调用和代理决策都被捕获为跨度，而无需对代理本身进行任何代码更改。

MLflow 的自动跟踪提供：

* **零代码更改**用于基本可观测性：自动日志记录挂钩到库级别的框架
* **跨多框架应用的统一跟踪**：LangChain、LangGraph 和自定义工具都出现在单个跟踪中
* **丰富的元数据**，包括输入、输出、令牌计数、模型名称和延迟
* **生产就绪的扩展**：跟踪异步发送以避免阻塞应用程序

=== OpenTelemetry 兼容性

MLflow 跟踪建立在 https://opentelemetry.io/[OpenTelemetry^] 之上，这是分布式跟踪的行业标准。这意味着你也可以将跟踪导出到其他后端（Jaeger、Zipkin、Grafana Tempo）以及 MLflow。

== 练习 4：探索用户会话

许多现实世界的 AI 应用程序使用会话来维护多轮用户交互。https://mlflow.org/docs/latest/genai/tracing/track-users-sessions/[MLflow 跟踪提供内置支持^]用于将跟踪与用户关联并将它们分组为会话。在 LLM 应用程序或 AI 代理中跟踪用户和会话为理解用户行为、分析对话流程和改进个性化提供了必要的上下文。

. 在 MLflow 中，点击 **可观测性** 下左侧边栏中的 **会话**：
+
image::sessions0.png[MLflow 左侧边栏，显示可观测性下的会话,link=self,window=blank,width=700]

. 在 mortgage-ai 应用程序中，每次聊天对话都作为会话跟踪。MLflow 将会话中的所有轮次分组在一起，让你看到完整的对话流程：

image::sessions1.png[MLflow 聊天会话视图，显示一个会话，7 轮，按用户和代理分组,link=self,window=blank,width=700]

点击会话会显示每轮及其输入和输出。你可以点击任何轮次上的 **查看完整跟踪** 直接跳转到详细跟踪视图：

image::sessions2.png[MLflow 会话详细信息，显示第 1 轮及其输入、输出和查看完整跟踪链接,link=self,window=blank,width=700]

这对于调试代理行为随时间下降的多轮对话特别有价值。你可以看到代理在每步拥有的完整上下文。

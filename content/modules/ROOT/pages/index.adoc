= 使用 Red Hat AI 的 AgentOps 可观测性

欢迎使用使用 Red Hat AI 的 AgentOps 可观测性工作坊！

== 你将学到什么

在本工作坊中，你将：

* 监控技术栈：利用 Red Hat AI 的开箱即用可观测性技术栈来跟踪你的智能体应用的关键指标和日志
* 追踪多智能体执行：跟踪跨多智能体框架和 MCP 工具的请求，以了解完整的决策路径
* LLM 评估：在 MLflow 中将追踪与 LLM 评估（Evals）相结合，确保你的代理保持高质量的输出
* 从开发到生产：从手动 notebook 评估转移到在平台上持续运行的自动化 AI 流水线

== 适用对象

本工作坊专为 SRE、平台工程师和 AI 开发者/工程师设计，他们希望为多智能体 AI 系统实施端到端可观测性。

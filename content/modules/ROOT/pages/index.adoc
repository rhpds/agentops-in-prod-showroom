= Red Hat AI を使用した AgentOps オブザーバビリティ

Red Hat AI を使用した AgentOps オブザーバビリティのワークショップへようこそ！

== 学習内容

このワークショップでは、以下のことを行います：

* スタックの監視: Red Hat AI のすぐに使えるオブザーバビリティスタックを活用して、エージェント型アプリの主要なメトリクスとログを追跡します
* マルチエージェント実行のトレース: マルチエージェントフレームワークと MCP ツールにまたがるリクエストを追跡し、完全な意思決定パスを理解します
* LLM 評価: MLflow でトレースと LLM 評価 (Evals) を組み合わせ、エージェントが高品質な出力を維持できるようにします
* 開発から本番環境へ: 手動のノートブック評価から、プラットフォーム上で継続的に実行される自動化された AI パイプラインへと移行します

== 対象者

このワークショップは、マルチエージェント AI システムのエンドツーエンドのオブザーバビリティを実装したい SRE、プラットフォームエンジニア、および AI 開発者/エンジニアを対象として設計されています。

== 前提条件

このワークショップでは、Kubernetes および AI/ML の概念に関する基本的な知識があることを前提としています。

== ワークショップ環境

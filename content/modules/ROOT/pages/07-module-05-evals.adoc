可观察性告诉你系统是否工作，但评估告诉你代理是否*工作得很好*。如果没有评估，答案质量下降 20% 可能会在几周内未被注意到，直到客户投诉。在本模块中，你将通过使用 MLflow 的评估框架、Prompt 注册表和 LLM-as-a-Judge 评分器（使用一个 LLM 评估另一个 LLM 的输出质量）对 Fed Aura Capital 潜在客户代理运行 LLM 评估，超越基本的可观察性。

TIP：在本模块中，你扮演 **AI 开发者/工程师角色**，专注于模型输出质量、prompt 管理和评估设计。

这是 AI 开发者的质量保证层，是*内循环*，你在开发期间手动评估代理输出。在模块 6 中，你将把它自动化为持续检测回归的*外循环*。

== 为什么评估对 AgentOps 很重要

在 Fed Aura Capital 抵押贷款系统中，代理做出重要决定：

* 潜在客户代理筛选销售线索。误报负面会损失 30 万美元的抵押贷款销售。
* 承保代理评估风险。批准 50 万美元的不良贷款会产生监管风险。
* 承保代理检查合规性。违规会面临法律处罚和执照暂停。

在生产环境中，即使是 1% 的错误率也意味着在每天 10,000 次互动中有 100 次失败。指标告诉你代理已响应。跟踪告诉你它是如何响应的。**评估告诉你它是否正确响应。**

== 练习 5：运行简单评估

回到 notebook，让我们从确定性评分器（使用简单规则对响应进行评分的自动化检查）开始，这些是不需要 LLM 调用的快速检查。这些是捕获明显回归的第一道防线。

=== 简单评分器

notebook 定义 3 个确定性评分器：

* **contains_expected**：响应是否包含预期关键字？（例如，FHA 问题响应是否提到 "FHA"？）
* **has_numeric_result**：响应是否包含数值，如美元金额或百分比？（对负担能力计算很重要）
* **response_length**：响应是否至少 50 个字符？（捕获空或截断的响应）

== 练习 6：运行 LLM-as-a-Judge 评估

确定性评分器捕获表面级别的问题，但无法评估响应是否*真正有用*。确定性评分器看到响应中的 "FHA" 并通过——但无法检测代理是否给出了错误的费率信息或违反了合规准则。为此，你需要 https://mlflow.org/docs/latest/genai/eval-monitor/running-evaluation/agents/[LLLM-as-a-Judge^]，使用 LLM 评估另一个 LLM 输出的质量。

=== LLM 评判评分器

notebook 在 3 个简单评分器之上添加了 5 个 LLM 驱动的评分器：

* **https://mlflow.org/docs/latest/genai/eval-monitor/scorers/llm-judge/tool-call/correctness/[ToolCallCorrectness^]**：代理是否调用了正确的工具？（例如，它是否对产品问题使用 `product_info`？）
* **ToolCallEfficiency**：工具调用是否最少且高效？
* **RelevanceToQuery**：响应是否与用户询问的内容相关？
* **Safety**：响应是否安全且适当？
* **Guidelines**：响应是否遵循自定义抵押贷款助手准则？（有帮助、无费率承诺、专业语言）

=== 运行评估

. 运行 **Run Full LLM-as-a-Judge Evaluation** 单元格。这会对 6 个测试用例运行所有 8 个评分器（3 个简单 + 5 个 LLM 评判）：
+
image::eval11.png[Notebook 运行 LLM-as-a-Judge 评估，带有 8 个评分器，包括 5 个 LLM 评判,link=self,window=blank,width=500]
+
此评估比简单评估花费更长时间，因为每个测试用例除了确定性检查外还由 5 个 LLM 评判进行评分。

== 练习 7：探索 prompt-跟踪链接

当生产中的质量下降时，prompt-跟踪链接使你能够在几秒钟而不是几天的手动关联内回答"哪个 prompt 版本导致了这个问题？"。MLflow 评估框架的关键特性之一是自动 prompt-跟踪链接。每个评估跟踪都链接到产生它的 prompt 版本，使你能够跟踪不同 prompt 迭代的质量。

. 在 MLflow UI 中，导航到 **Prompts** 并点击 **public-assistant-system-prompt**。点击 **跟踪** 标签页：
+
image::eval15.png[MLflow Prompts 跟踪标签页，显示链接到 prompt 版本 1 的评估跟踪,link=self,window=blank,width=700]
+

所有评估跟踪都自动链接到产生它们的 prompt 版本。当你更新系统 prompt 并注册版本 2 时，未来的评估将链接到该新版本，使你能够并排比较不同 prompt 迭代的质量。

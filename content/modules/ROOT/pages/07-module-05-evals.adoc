Observability tells you if your system is working, but evaluations tell you if your agents are working *well*. In this module, you'll go beyond basic observability by combining tracing with LLM evaluations in MLflow, ensuring Acme FinTech's agents maintain high-quality outputs alongside system reliability.

This is the AI Developer's quality assurance layer -- ensuring that agents don't just respond, but respond correctly.

== Learning objectives

By the end of this module, you'll be able to:

* Explain the role of LLM evaluations in AgentOps observability
* Create evaluation datasets from production traces
* Configure MLflow scorers for agent output quality
* Establish quality baselines and monitor for regression

== Why evaluations matter for AgentOps

In the Acme FinTech mortgage system, agents make consequential decisions:

* The prospect agent qualifies leads -- wrong qualification costs sales
* The underwriter agent assesses risk -- incorrect assessment creates liability
* The compliance agent checks regulations -- failures risk legal penalties

Metrics tell you the agent responded. Traces tell you how it responded. **Evaluations tell you if it responded correctly.**

== Exercise 3: Define evaluation scorers

Scorers determine how agent outputs are evaluated. Let's create scorers for the Acme FinTech prospect agent.

. Create a Python script with custom scorers:
+
[source,python]
----
# scorers.py
from mlflow.metrics import make_metric

def qualification_accuracy(predictions, targets):
    """Score whether the qualification decision matches expected."""
    correct = 0
    for pred, target in zip(predictions, targets):
        if pred.get("qualified") == target.get("qualified"):
            correct += 1
    return correct / len(predictions) if predictions else 0

def confidence_calibration(predictions, targets):
    """Score how well confidence correlates with correctness."""
    # High confidence should mean correct predictions
    calibration_score = 0
    for pred, target in zip(predictions, targets):
        is_correct = pred.get("qualified") == target.get("qualified")
        confidence = pred.get("confidence", 0.5)
        if is_correct and confidence > 0.8:
            calibration_score += 1
        elif not is_correct and confidence < 0.5:
            calibration_score += 0.5
    return calibration_score / len(predictions) if predictions else 0

def rejection_reason_accuracy(predictions, targets):
    """For rejections, check if the reason matches."""
    rejections = [(p, t) for p, t in zip(predictions, targets)
                  if not t.get("qualified")]
    if not rejections:
        return 1.0  # No rejections to evaluate

    correct = sum(1 for p, t in rejections
                  if p.get("rejection_reason") == t.get("rejection_reason"))
    return correct / len(rejections)
----

from mlflow.metrics import make_metric
import os

# Set MLflow tracking

mlflow.set_experiment("acme-fintech-evals")

    dataset = json.load(f)

# Define scorers

    correct = sum(1 for p, t in zip(predictions, targets)
                  if p.get("qualified") == t.get("qualified"))
    return correct / len(predictions) if predictions else 0

# Run evaluation
with mlflow.start_run(run_name="prospect-agent-baseline"):
    # Log dataset info
    mlflow.log_param("dataset_size", len(dataset))
    mlflow.log_param("dataset_tags", list(set(tag for d in dataset for tag in d.get("tags", []))))

    # Simulate getting predictions (in real scenario, call the agent)
    # For demo, we'll assume predictions match expected outputs
    predictions = [d["expected_output"] for d in dataset]
    targets = [d["expected_output"] for d in dataset]

    # Calculate and log metrics
    accuracy = qualification_accuracy(predictions, targets)
    mlflow.log_metric("qualification_accuracy", accuracy)
    mlflow.log_metric("dataset_coverage", len(dataset))

    print(f"Qualification Accuracy: {accuracy}")
    print("Evaluation logged to MLflow")

== Exercise 5: Monitor for quality regression

Now let's set up a process to detect when agent quality degrades.

. Create a regression detection script:
+
[source,bash]
----
cat << 'EOF' > /tmp/acme-fintech-evals/regression_check.py
import json
import mlflow
import os

mlflow.set_tracking_uri(os.environ.get("MLFLOW_TRACKING_URI"))
mlflow.set_experiment("acme-fintech-evals")

# Define thresholds
THRESHOLDS = {
    "qualification_accuracy": 0.90,
    "confidence_calibration": 0.80,
    "rejection_precision": 0.85
}

def check_regression(current_metrics, thresholds):
    """Check if any metric falls below threshold."""
    regressions = []
    for metric, threshold in thresholds.items():
        current = current_metrics.get(metric, 0)
        if current < threshold:
            regressions.append({
                "metric": metric,
                "current": current,
                "threshold": threshold,
                "delta": threshold - current
            })
    return regressions

# Simulate current metrics (in production, these come from actual evaluation)
current_metrics = {
    "qualification_accuracy": 0.93,
    "confidence_calibration": 0.85,
    "rejection_precision": 0.91
}

with mlflow.start_run(run_name="regression-check"):
    # Log current metrics
    for metric, value in current_metrics.items():
        mlflow.log_metric(metric, value)

    # Check for regressions
    regressions = check_regression(current_metrics, THRESHOLDS)

    if regressions:
        print("⚠️  REGRESSION DETECTED!")
        for r in regressions:
            print(f"  - {r['metric']}: {r['current']:.2f} (threshold: {r['threshold']:.2f})")
        mlflow.set_tag("regression_detected", "true")
    else:
        print("✅ All metrics within acceptable range")
        mlflow.set_tag("regression_detected", "false")

    mlflow.log_param("thresholds", json.dumps(THRESHOLDS))
EOF

python3 /tmp/acme-fintech-evals/regression_check.py

== Troubleshooting

**Issue**: Evaluation script fails with import errors
**Solution**:

. Ensure MLflow is installed: `pip install mlflow`
. Check Python version: `python3 --version` (needs 3.8+)
. Verify all dependencies: `pip install pandas numpy`

**Issue**: Cannot connect to MLflow from evaluation script
**Solution**:

. Verify MLFLOW_TRACKING_URI is set: `echo $MLFLOW_TRACKING_URI`
. Check network access from your environment
. If running locally, ensure port-forwarding is active
. Try using the internal service URL from within the cluster

**Issue**: Evaluation metrics not appearing in MLflow
**Solution**:

. Check that `mlflow.log_metric()` calls are executing
. Verify the experiment name matches
. Look for Python exceptions in script output
. Ensure the run is properly ended with `mlflow.end_run()` or context manager

**Issue**: Baseline comparison not working
**Solution**:

. Verify baseline run is tagged correctly: `tags.baseline = "true"`
. Check experiment ID matches between baseline and current runs
. Ensure metric names are consistent

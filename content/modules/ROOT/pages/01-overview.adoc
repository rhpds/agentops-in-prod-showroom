== 什么是 AgentOps（智能体运维）？

传统 DevOps 体系教会我们如何对生产环境软件系统进行监控、排障与运维。但 AI 智能体带来了全新难题：行为不可确定性、多智能体协同调度、大模型输出质量波动、分布式工具调用链路复杂等问题。

**AgentOps** 将可观测性能力延伸适配 AI 智能体场景。除了常规的请求量、延迟指标监控外，你还需要追踪智能体的推理链路、统计 Token 消耗、校验工具调用成功率，并持续评估模型输出质量。

本次工作坊将带你完整落地这套能力。

Traditional DevOps taught us to monitor, debug, and maintain software systems in production. But AI agents introduce new challenges: non-deterministic behavior, multi-agent orchestration, LLM quality variations, and distributed tool calls.

**AgentOps** extends observability practices to handle these realities. Beyond tracking request rates and latency, you need to trace agent reasoning paths, measure token consumption, validate tool call success, and continuously evaluate output quality.

This workshop shows you how.

== 你的身份与任务背景

你是联邦奥若资本（Fed Aura Capital）的高级工程师。这是一家抵押贷款企业，已上线一套成熟的多智能体 AI 系统，覆盖完整贷款业务全流程。系统包含 5 个独立 LangGraph 智能体，分别承担不同业务角色：客户咨询接待、借款人申请录入、信贷专员流程管理、风控合规审核、高管数据分析。

公司 CTO 紧急召开会议提出诉求：
“我们生产环境的 AI 智能体频繁异常，但我们完全无法定位故障节点与根因。客户投诉量持续上涨，贷款处理时长波动极大，整套多智能体工作流内部运行状态完全不可见。我们急需端到端全链路可观测能力，且需要尽快落地。”

**你的工作任务**: 基于红帽 OpenShift AI 搭建一套完整的 AgentOps 可观测体系，实现多智能体系统全链路可视化。

**核心目标**: 搭建监控、链路追踪、模型评估一体化能力，让团队能够快速定位分布式故障、理清智能体决策逻辑、保障全 AI 业务流程输出质量稳定合规。

== 联邦奥若资本现存业务痛点

**现状说明**: 公司已部署处理抵押贷款申请的多智能体 AI 系统，但跨智能体、跨 MCP（模型上下文协议，用于连接 AI 智能体与外部工具、数据源的标准协议）工具的分布式工作流完全缺乏可视化能力。

**项目时限**: 董事会要求工程团队两周内完成可观测能力落地演示，并实现故障响应时效优化。

**当前运营痛点** :

* **智能体交互链路完全黑盒**: 贷款申请流程异常时，团队无法追溯 5 个智能体之间完整请求流转路径，只能耗费数小时人工拼凑日志排查问题。
* **隐性延迟瓶颈无法定位**: 部分智能体处理耗时波动极大，但没有任何手段定位延迟来源，客户持续反馈审批流程卡顿
* **MCP 工具调用静默失效**: 合规校验、信用评分等外部工具调用失败时无告警，大量不完整贷款申请往往延迟数天才被发现。
* **无统一输出质量基准**: 缺少标准化手段评估智能体回复的一致性与准确性，大幅提升合规违规风险。

**解决方案契机**: 红帽 OpenShift AI 内置一体化可观测组件栈，可一站式解决上述全部痛点。本次由你负责完成方案验证并落地适配公司抵押贷款业务场景。

**技术侧思路**: “MLflow 链路追踪搭配 RHOAI 指标监控套件，能够补齐我们缺失的可视化能力，但我们需要验证该方案与 LangGraph 智能体、MCP 工具的集成适配效果。”

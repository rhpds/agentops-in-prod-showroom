== このワークショップの進め方

このワークショップは段階的に構築されています。各モジュールは、前のモジュールの概念に基づいています。

**基礎 (モジュール 1-2)**: マルチエージェントアプリケーションと中核となるオブザーバビリティの概念を理解します。これらのモジュールは、その後に続くすべての土台となります。

**中核的な実践 (モジュール 3-4)**: メトリクス、ログ、トレースを直接操作します。Grafanaダッシュボードを探索し、マルチエージェントシステム用にMLflowトレースを設定します。

**高度なトピック (オプション) (モジュール 5-6)**: より高度な知識を持つ方や早く終わった方向けに、LLMの評価と自動化された品質モニタリングを実装します。これらのモジュールには追加の時間が必要ですが、品質保証に関するより深い専門知識を得ることができます。

必要に応じて前のモジュールを見直してください。概念は互いに積み重なっているため、後で不明な点が出てきた場合は戻って復習してください。

== ワークショップUIの理解と操作

ワークショップのインターフェースは、自分の環境で作業しながら手順を読めるように設計されています。

**左パネル**: ワークショップの手順とコンテンツ

**右パネル**: 実践演習用の環境タブ

* **OCP Console**: クラスターを管理するためのOpenShift Webコンソール
* **Terminal**: CLIコマンドを実行するためのコマンドラインアクセス
* **MLflow Console**: トレースと実験を表示するためのMLflow UI
* **Mortgage AI App**: 観察対象のマルチエージェントアプリケーション
* **Grafana**: メトリクスとログのダッシュボード
* **RHOAI Console**: Red Hat OpenShift AIのダッシュボード

**表示モード** (トップナビゲーション):

image::view-modes.png[]

* **Instructions**: 手順の全画面表示 (環境タブを非表示)
* **Split**: 左右分割表示 (現在のデフォルト) - 手順と環境の両方を表示
* **Tabs**: 環境の全画面表示 (手順を非表示)

**レイアウトの調整**: 分割（Split）モードでは、中央の境界線を左右にドラッグしてパネルのサイズを変更できます。

TIP: ほとんどの演習は、環境タブで作業しながら手順を参照できる分割表示モードで行うのが最適です。

== ヘルプが必要な場合

ワークショップ中に行き詰まった場合は：

* **以下の用語集を確認する**: 重要な用語や概念は、折りたたみ式の用語集セクションで定義されています
* **前のモジュールを見直す**: 概念は積み重なっていくため、以前のコンテンツを見直すことで、その後の内容が明確になることがよくあります
* **ドキュメントのリンクを参照する**: 各モジュールには、より深く探求するための公式ドキュメントへのリンクが含まれています
* **演習をもう一度試す**: 実践的な演習を行うことで、最初に見落としていた詳細が明らかになることがよくあります
* **まとめを参照する**: 「推奨リソース」セクションには、トピックごとに整理された追加の学習資料があります

== 用語集

[%collapsible]
.このワークショップで使用される重要な用語 (クリックして展開)
====
[cols="1,3",options="header"]
|===
|用語 |定義

|AgentOps
|エージェントオペレーション。本番環境でAIエージェントシステムを監視、トレース、評価、および保守するための原則

|AIエージェント
|タスクについて推論し、どのツールを呼び出すかを決定し、自律的なアクションを実行するためにLLMを使用するシステム

|LLM
|大規模言語モデル。大量のテキストデータセットでトレーニングされ、自然言語を生成および理解できるAIモデル

|MCP
|Model Context Protocol。AIエージェントを外部ツールやデータソースに接続するための標準規格

|LangGraph
|LangChainの上に構築された、ステートフルなマルチエージェントAIワークフローを構築するためのフレームワーク

|RAG
|Retrieval-Augmented Generation (検索拡張生成)。回答を生成する前に関連するドキュメントを検索することで、LLMの応答を強化するパターン

|トレース
|スパンで構成される、分散システムを通過するリクエストの完全な記録

|スパン
|トレース内の単一の操作 (例: 1回のLLM呼び出し、1回のツール呼び出し)

|スコアラー
|エージェントの応答の品質を評価する関数 (決定論的またはLLM駆動)

|インナーループ
|手動で開発者主導の評価ワークフロー (例: Jupyterノートブックから評価を実行する)

|アウターループ
|自動化されたプラットフォーム主導の評価ワークフロー (例: スケジュールされたAIパイプライン)

|RBAC
|Role-Based Access Control (ロールベースのアクセス制御)。ユーザーのロールに基づいてシステムアクセスを制限する

|pgvector
|埋め込み(Embeddings)のベクトル類似度検索を可能にするPostgreSQL拡張機能

|PromQL
|Prometheus Query Language。Grafanaダッシュボードでメトリクスをクエリするために使用される

|LogQL
|Log Query Language。LokiStack/Grafana Lokiでログをクエリするために使用される
|===
====
